How to trust this page

Every change to every score — whether you or an automated run made it — is recorded the instant it happens: a timestamp, the exact before-and-after value, and a permanent fingerprint. Because each entry is cryptographically chained to the one before it, an old record can't be quietly altered without breaking every record that follows. Nothing changes here without a permanent, tamper-evident trail.

This page reads that log directly and lays out every run in plain language — no code, no digging required. Each run below carries the same permanent fingerprint recorded in the system underneath, shown right on the entry so you can see it’s stamped.
